ECE-128-Lab-4
This project implements a vehicle safety interlock and warning system using combinational logic in Verilog. The system uses different vehicle sensor inputs to determine whether the vehicle can start and whether different warning signals should be activated. The design was simulated in Vivado and implemented on the Basys 3 FPGA board using switches as inputs and LEDs as outputs.

Simulation
1. Open the project in Vivado.
2. Add the Verilog source code and testbench.
3. Run the behavioral simulation.
4. Use the waveform to verify that the outputs respond correctly to the different input conditions.

FPGA Implementation
1. Add the XDC constraints file to the project.
2. Run synthesis and implementation.
3. Generate the bitstream.
4. Connect and program the Basys 3 FPGA board.
5. Use the switches to change the vehicle sensor inputs and observe the corresponding outputs on the LEDs.
